# Community Code of Conduct

Be respectful, constructive and specific when discussing issues, pull requests and project decisions. Critique code and evidence rather than people. Welcome contributors with different experience levels and backgrounds.

Harassment, threats, discriminatory abuse, deliberate disclosure of private information, impersonation and spam are not acceptable. Do not post client data or credentials in project discussions.

Maintainers may edit or remove inappropriate content, close disruptive conversations or restrict participation using GitHub's moderation tools. Responses should be proportionate to the conduct and its impact.

For a public concern, contact the repository maintainer through an issue that contains no private details. For harassment, threats or sensitive personal information, use GitHub's private Report abuse flow on the relevant content or account. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
