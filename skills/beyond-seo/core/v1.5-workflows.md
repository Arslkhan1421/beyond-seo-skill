# v1.5 input contracts and CLI workflows

## Offline host-agent pipeline
```text
python tools/audit_runner.py --config audit-config.json --crawl-snapshot pages.json --serp-snapshot serp.json --output-dir output/site-new-date
```
Aliases: --pages-json and --serp-json. A crawl snapshot disables network crawl, Apify, PageSpeed/Lighthouse and Clarity collectors. Local first-party CSV imports still work. No token is required. --serp-snapshot alone replaces search collection but still performs the configured native crawl.

pages.json is an object with nonempty pages array, optional coverage and optional sitemap:
```json
{"pages":[{"url":"https://example.com/","final_url":"https://example.com/","status":200,"html":"<html><title>Example</title><h1>Example</h1></html>","headers":{"Content-Type":"text/html"},"collected_at":"2026-10-15T09:00:00Z","source_url":"https://example.com/","method":"Host browser serialized DOM after load","rendered":true}],"coverage":{"discovered_urls":1},"sitemap":{"complete":false,"urls":[]}}
```
Use fetched HTML or serialized DOM, never prose disguised as HTML. A browser tool succeeding does not prove HTTP 200: use status null if unavailable, which stays out of HTTP scoring. Preserve real source timestamps and collection methods; parsed observations are retained with response hashes. Coverage always remains partial unless independently established; this mode makes no fresh-fetch claim. Complete sitemap metadata requires source_url and collected_at; omission findings need real successful traversal. Raw HTML originals remain private outside the package.

serp.json:
```json
{"queries":[{"query":"example service","country":"US","language":"en","device":"desktop","collected_at":"2026-10-15T09:00:00Z","source_url":"https://www.google.com/search?q=example+service","method":"Native search tool; organic results only","organic_results":[{"url":"https://example.com/","title":"Example"}]}]}
```
Results must be in observed organic order, not reconstructed ranks. Exclude ads/maps/widgets from ordinal position. Empty arrays are Not verified. Search data is one localized sample, not rank tracking or volume. Collection context is retained per query.

## Utilities
- `tools/url_classifier.py --input pages.csv --output classified.json`: URL/url/Address plus optional title and h1. Page roles are inferred.
- `tools/backlink_classifier.py --input links.csv --source ahrefs --provenance owner_export --terms software CRM --output links.json --csv-output links-reviewed.csv`: Ahrefs/Semrush/Moz normalized source/target aliases, lexical relevance matches and repeated-domain/template-placement patterns. No invented toxicity score or automatic disavow.
- `tools/sitemap_extractor.py --input sitemap.xml.gz --crawl-json crawl-observations.json --output sitemap-review.json`: local relative child files must remain beneath the input directory; remote child URLs are reported as unvisited. HTTP(S) input uses bounded, host-restricted pinned crawling; gzip decompression is bounded. Not-crawled is not orphaned.
- `tools/check_environment.py --native-browse --native-search --files gsc.csv`: declared host capabilities, existing exports and dependency/token presence. Configuration is not a successful authentication test.
- `tools/schema_validator.py --html page.html --visible-text rendered.txt --output schema.json`: object/array/@graph parsing, local @id references, review profiles for Organization, LocalBusiness, Service, Product, FAQPage, Article and Person. Local profile properties are not universal Google requirements. Prices, ratings, FAQs and NAP are text-match review candidates. Save rendered evidence separately; no false eligibility pass.
- `tools/cannibalization_check.py --input query-pages.csv --crawl-json crawl-observations.json --output overlap.json`: normalized query,page,clicks,impressions, optional dimensions. One property/window/segment, no total rows or overlapping exports. Shared-query shares, identical title/H1 groups and sampled internal graph. Validate export provenance first. Consolidate + 301 requires equivalent intent and owner review; no automatic destructive actions.
- `tools/international_checks.py --input crawl-observations.json --output international.json`: see international audit module.

## URL-level first-party synthesis
`tools/funnel_joiner.py --input funnel-config.json --output funnel.json`.
Input:
```json
{"website_url":"https://example.com/","sources":{"gsc":{"csv":"gsc.csv","metadata":{}},"ga4":{"csv":"ga4.csv","metadata":{}},"clarity":{"csv":"clarity.csv","metadata":{}}},"thresholds":{"min_impressions":100,"low_ctr":0.02,"min_clicks":20,"min_sessions":20,"friction_rate":0.1,"low_events_per_session":0.01,"high_events_per_session":0.05}}
```
Replace each metadata object using the existing first-party contract: source, property, website_url, provenance (owner_export/authenticated_api), retrieved_at, start_date, end_date, timezone (IANA), dimensions and filters. All sources must have identical measurement dates, timezone and nonempty join_scope object describing shared country/device/URL scope. GSC requires search_type web and page in dimensions; GA4 requires dimensions [page], filters.channel Organic Search and key_event_definition. Clarity requires dimensions [page], website_url and explicit organic_source_mapping documenting organic segmentation. Clarity CSV: page,sessions,quick_back_sessions,rage_click_sessions,dead_click_sessions, each friction field a session count (not percentage or click total). Reject duplicate Clarity page rows and impossible counts. GSC/GA4 normalized metrics come from core/import-schemas.json. Failed quality/compatibility checks return Not comparable and no diagnoses.

URLs retain scheme, trailing slash and query. Relative landing paths resolve against website_url; reconcile Google-selected canonicals with explicit owner evidence rather than silently folding variants. Missing source rows stay null; zero denominators stay undefined. GSC position is impression-weighted within a compatible export; query-limited totals can understate property metrics. GA4 key_events/session is not session conversion rate, a qualified lead rate, or a cross-source funnel denominator. Friction categories may overlap, so use their maximum rate, never their sum.

Rules flag snippet/query/position review, possible landing intent or UX friction, and converting mid-position pages for link/content review. Thresholds are configurable examples, not benchmarks. Outputs retain source checksums/metadata; no causal diagnosis or highest-ROI promise.

## Shared import schemas

The query-overlap CLI also accepts --crawl-json alone. Metadata similarity uses token Jaccard (default 0.85; --similarity-threshold), capped at 500 sampled pages. Template and regional overlap require contextual review.

Complete sitemap snapshots must explicitly supply status 200 along with source_url and collected_at. Set report_timezone in audit config when the report date should use a local IANA timezone; collection timestamps remain unchanged.
core/import-schemas.json contains all former vendor CSV headers plus normalized required metric columns. Vendor templates document source shapes; they do not automatically normalize exports or confer verification. source_classifier.py and first_party_quality.py read the same registry.

## Release validation
Run unittest discovery, validate_skill.py, frontmatter validation and an offline pipeline with sockets blocked. Maintain both positive and negative fixtures. Synthetic fixtures prove contracts, not live SEO accuracy; prior real-site observations remain separate dated artifacts. build_manifest.py inventories the portable package; exclude credentials, caches, private outputs and local environments.
