## 30-day-plan

# 30-Day SEO Action Plan

The 30-day plan is for urgent fixes, technical foundation, highest-value page improvements, and measurement setup.

The agent must not recommend 30 days of random activity. The first month must remove blockers and create the fastest path to measurable growth.

---

## 1. Purpose

The 30-day plan answers:

```text
What must be fixed immediately so SEO work can start producing results?
What pages should be improved first?
What tracking must be installed?
What quick wins can move rankings, traffic, or queries?
```

---

## 2. Inputs

Use:

```text
Full site audit
Technical audit
Keyword-to-page map
Competitor gap
Content gap
Local SEO audit
Backlink audit
AEO/GEO audit
Conversion audit
GSC/GA4/GBP data if available
```

---

## 3. 30-Day Priority Buckets

### Bucket 1: Measurement and Tracking

Fix first if missing:

```text
Google Search Console
GA4
Form submit tracking
Phone click tracking
WhatsApp click tracking
Booking/enrollment tracking
GBP UTM links
Thank-you pages or conversion events
```

If tracking is missing, the campaign cannot prove ROI.

### Bucket 2: Technical Blockers

Fix:

```text
Noindex on important pages
Blocked pages
Broken money pages
Wrong canonicals
JS-rendering problems
Duplicate metadata templates
Missing sitemap pages
404/5xx on important URLs
Broken forms/buttons
```

### Bucket 3: Existing Winners

Improve pages already ranking or close to ranking:

```text
Top 1-5 keywords: defend and improve conversion
Positions 4-20: fastest SEO wins
High-impression low-CTR pages: improve title/meta
High-traffic low-conversion pages: improve CTA/trust
```

### Bucket 4: Highest-Value Money Pages

Improve or create pages that directly support leads/sales:

```text
Main service page
Main course page
Location service page
Emergency/urgent page
Best existing commercial page
```

### Bucket 5: Local and GBP Quick Wins

For local businesses:

```text
GBP categories
Services/products
Photos
Reviews/review request flow
Q&A
Posts
Appointment link
UTM tracking
NAP consistency
```

### Bucket 6: Safe Authority Foundations

Start:

```text
Local citations
Association profiles
Partner/vendor links
Free article support posts from approved source library
Brand/entity profiles
High-quality directories
```

Do not start spam link buying in month one.

## 500-query-growth-model

# 500-Query Growth Model

This file defines how Beyond SEO models lead/query targets such as 500 qualified queries per month.

The goal is to prevent fake SEO promises and connect rankings, traffic, local SEO, backlinks, and conversion.

---

## 1. Core Formula

```text
Required qualified visits/interactions = Target queries ÷ Conversion rate
```

Example:

```text
500 queries/month at 10% conversion = 5,000 qualified visits/interactions
500 queries/month at 7% conversion = 7,143 qualified visits/interactions
500 queries/month at 5% conversion = 10,000 qualified visits/interactions
```

---

## 2. Query Sources

Qualified queries may come from:

```text
Organic service pages
Organic blog/support pages
Google Business Profile
Direct/brand traffic
Referral/backlink traffic
Social-assisted traffic
Paid retargeting
Email/WhatsApp follow-up
```

SEO should not pretend all queries come only from blog traffic.

---

## 3. Required Inputs

Use:

```text
Target queries
Current organic traffic
Current GSC clicks/impressions
Current GBP calls/directions
Current GA4 conversions
Current conversion rate
Current ranking footprint
Current authority/backlinks
Service/page architecture
Competitor footprint
```

If unavailable, label assumptions.

---

## 4. Model Template

```text

Current verified organic visits:
Current verified GBP actions:
Current conversion rate:

```

---

## 5. Growth Lever Split

Break target into levers:

```text

GBP/local actions:
Brand/direct:
Referral/backlink assisted:

```

Example:

```text

75 from support articles
50 from brand/direct
25 from referral/PR
```

Adjust based on business type.

## content-optimizer

# Content Optimizer

Use this module when the user asks to improve pages, rewrite SEO text, create content briefs, build service pages, optimize existing content, or create AEO/GEO answer-ready sections.

## Inputs

- Target page URL and current page text when available.
- Target service/product, location, audience, and conversion goal.
- Keyword/SERP evidence and competitor examples.
- Brand tone and required compliance notes when supplied.

## Optimization Workflow

1. Identify the primary intent and business value of the page.
2. Check whether the page has a clear title, H1, opening value proposition, service definition, proof, process, FAQs, internal links, schema, and CTA.
3. Use competitor and SERP evidence to find missing sections.
4. Produce improvement text that can be implemented directly.
5. Avoid keyword stuffing and unsupported claims.
6. Add AEO/GEO blocks only when they help users: definitions, short answers, comparisons, steps, costs, risks, examples, and FAQs.

## Required Output For Page Improvements

For each page include:

```text
Current problem
Why it matters
Recommended title tag
Recommended meta description
Recommended H1
Recommended section outline
FAQ ideas
Schema notes
Internal links in
Internal links out
CTA improvement
Evidence label
Priority
```

## Writing Rules

- Make titles specific to service, location, and value where appropriate.
- Keep meta descriptions written for clicks, not rankings alone.
- Keep H1 natural and clear.
- Use page sections that answer real buying objections.
- Put proof near CTAs: case studies, numbers, testimonials, credentials, partner logos, or process evidence when available.
- Do not invent reviews, awards, client names, metrics, guarantees, or case outcomes.

## Content Brief Mode

When asked to create a new page or article, provide:

- Target URL.
- Primary and secondary keywords.
- Search intent.
- Title/H1/meta.
- Required sections.
- FAQs.
- Schema.
- Internal links.
- CTA.
- Trust proof needed.
- Word count range.
- Risk notes.
