# Content Optimizer

Use this module when the user asks to improve pages, rewrite SEO text, create content briefs, build service pages, optimize existing content, or create AEO/GEO answer-ready sections.

## Inputs

- Target page URL and current page text when available.
- Target service/product, location, audience, and conversion goal.
- Keyword/SERP evidence and competitor examples.
- Brand tone and required compliance notes when supplied.

## Optimization Workflow

1. Identify the primary intent and business value of the page.
2. Check whether the page has a clear title, H1, opening value proposition, service definition, proof, process, FAQs, internal links, schema, and CTA.
3. Use competitor and SERP evidence to find missing sections.
4. Produce improvement text that can be implemented directly.
5. Avoid keyword stuffing and unsupported claims.
6. Add AEO/GEO blocks only when they help users: definitions, short answers, comparisons, steps, costs, risks, examples, and FAQs.

## Required Output For Page Improvements

For each page include:

```text
Current problem
Why it matters
Recommended title tag
Recommended meta description
Recommended H1
Recommended section outline
FAQ ideas
Schema notes
Internal links in
Internal links out
CTA improvement
Evidence label
Priority
```

## Writing Rules

- Make titles specific to service, location, and value where appropriate.
- Keep meta descriptions written for clicks, not rankings alone.
- Keep H1 natural and clear.
- Use page sections that answer real buying objections.
- Put proof near CTAs: case studies, numbers, testimonials, credentials, partner logos, or process evidence when available.
- Do not invent reviews, awards, client names, metrics, guarantees, or case outcomes.

## Content Brief Mode

When asked to create a new page or article, provide:

- Target URL.
- Primary and secondary keywords.
- Search intent.
- Title/H1/meta.
- Required sections.
- FAQs.
- Schema.
- Internal links.
- CTA.
- Trust proof needed.
- Word count range.
- Risk notes.
